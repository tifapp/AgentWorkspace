# Desktop interactions

The live Settings > Advanced controls open Maps, Capture context into map, Work interactions and External effects. Task menus open interactions scoped to the selected task. `--ui-preview` provides visual/control inspection only: it does not create a real capture controller, global hotkey, project runtime or effect action.

Capture first retains an external foreground HWND, PID and process creation identity. The configurable global hotkey captures before Agent OS takes focus. In-app/tray capture attempts bounded foreground reactivation, then rechecks identity; failure reports a reason without capturing a different window. The review shows bounded UIA text and optional screenshot, supports redaction and an explicit crop. Sending the screenshot to Codex requires opt-in. Generate calls isolated `CodexContextMicroagent`: title must identify the foreground source, exactly three suggestions and at most eight generated nodes are accepted. Users may add more nodes manually. Suggestions only fill editable fields. Saving a map and starting selected tasks are separate confirmations. Accepted text/image bytes are immutable, hashed and passed as untrusted `additionalContext` only to explicitly started work.

Maps displays a draggable, zoomable canvas with task cards, dependency/related/followup edges, layout, citations and attempt lineage. Draft edits save with revision checks; cycles and missing dependencies are refused. Selected ready tasks can start while other map nodes remain pending, including on an active map. Task result citations and manually added nodes are supported. The status follows actual task outcomes.

Work interactions reads the durable task journal. Active tasks can receive steering; a reply after completion creates a child followup with parent lineage. Clarifications can be answered, peer requests acknowledged or handed to another active task, waits inspected/resolved/canceled, required obligations resolved, and followup proposals accepted or rejected. Proposals never auto-start. The inbox and acknowledgement are scoped to exact work/interaction IDs.

External effects opens separate prepared-scope review. Approval is bound to the displayed digest; execution and reconciliation require configuration and explicit actions. Notification history, quiet hours, tray navigation and close guard are local desktop controls. No external credentials or effects were exercised here.

Native App build 73d completed with zero warnings/errors. UIA controls and bounds were verified at wide and narrow preview sizes. Screenshots from the current session and retained 3fbb baseline are blank, so rendered visual appearance is unverified.
