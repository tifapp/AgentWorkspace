# Product objective: replace resource-checkin for supported work

Agent OS aims to make routine Codex development on this Windows user account proceed without resource-checkin bookkeeping. The runtime derives supported resource identities, owns effects and waits, validates combined output, records narrow authority and recovers uncertain outcomes. The historical retirement archive/receipt records the earlier cutover; it is not rerun by this source delivery.

Supported source now includes AppContainer PowerShell and private Git, canonical repository profiles and conditional SMB, typed claims, owned processes/previews, task maps and scoped interactions, explicit Hyper-V native SDK isolation, configured external-effect adapters, and signed update protocol. See [guarantees](guarantees.md). Supported managed effects do not protect arbitrary unmanaged Windows programs, other accounts or unconfigured remote operations. Phone and other agent hosts/platforms are excluded.

## Acceptance measures

For a matched workflow, record valid completed work, elapsed time and recovery, agent coordination commands/tokens, human interruptions, false waits, escaped effects, stale resumptions and duplicate effects. Retain source manifest, Codex version/model/configuration, project revision and exact validation command. Compare independent and conflicting tasks, combined Git publication, child process cancellation, shared resources, waits/peer obligations, runtime death, scoped decisions, and active legacy work. The historical 11-repetition no-op coordination benchmark measured a narrower overhead advantage; it does not establish whole-task throughput or model-token superiority for this source.

The exact archived `0d8a7e9` source passed its root-native 71/71 integration suite through compiled `Tests.exe`; the receipt pins archive and DLL hashes. Native App build 73d had zero warnings/errors. Capture and authenticated drafting fixtures passed their bounded scenarios. UIA controls/bounds passed preview checks; blank screenshots leave visual rendering unverified. Real VM, live external destinations and production signing/install need separate prerequisites and proof. [Validation report](validation-report.md) records these distinctions.

Phone work is deferred and explicitly excluded; no mobile app, relay, pairing, phone notifications or phone control is in this release.
