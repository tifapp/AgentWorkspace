# Coordination kernel decision — 2026-10-07

Source: user-approved end state and acceptance plan supplied 2026-10-07; baseline revision main eae2297. This is a prospective decision, not implementation or executed acceptance. The isolated documentation clone is to be integrated by the requester into original main after validation.

Agent OS is to become a per-user Windows task and coordination service independent of Git. Actions are durable obligations with separately identified attempts and participants; failed execution does not close an Action. WorkUnit.Id remains an execution identity linked to a distinct Action.Id. Tasks and optional contexts can exist without repository/project/folder/command/session. One service owns a new SQLite authority database; workers execute effects/delivery/export/previews. CLI, desktop, scheduler and authenticated host tools use the same revision, authorization and idempotency rules. Git remains optional for private source work and expected-old publication. Existing confinement and features must survive.

The exact public projection, logical schema, invariants, module/API ownership, 85-case mapping, verification matrix, vertical stages, and cutover/rollback gate are specified in [the coordination kernel plan](../docs/coordination-kernel.md). Its N catalogue evidence marks new-kernel checks not yet executed. Existing [guarantees](../docs/guarantees.md) and [open verification](open.md) describe the old runtime and fixture/live limits. Historical retirement receipts cover only the prior runtime. The original main eae2297 had no active tasks or pending publication in the saved state; the prior documentation run could not resolve its ref and this fresh clone is based on main. Concurrent original-main work must be preserved on integration.

Do not claim the new service, tests, live VM/SMB/external behavior, installed cutover, or v14/v15 wire compatibility from this decision. The final authority transition requires all recorded gates, drained or relinquished legacy tasks, no remaining writers, archived old files, and no simultaneous authorities; the user has already authorized that end state subject to gates.
